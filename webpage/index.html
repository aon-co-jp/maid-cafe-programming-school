🎓 Maid Cafe Programming School

VS Code extension — companion to open-english / open-englishの相棒拡張機能

EN

What is this?

Maid Cafe Programming School is a free, open-source VS Code extension that lets you ask your local aruaru-llm AI teacher — grounded by aruaru-search (unlimited, no API key needed) — questions right from your editor, with your selected code and file path attached automatically. It exists because open-english's browser chat alone couldn't pass editor context (selected code, file paths) to the AI teacher, limiting the "learn while you build" experience to copy-pasting back and forth.

Highlights:

  • Ask the AI teacher with your selected code + file path attached, from the command palette or a status-bar icon
  • Optionally study relevant programming basics at the same time as you build
  • Switch AI teacher: aruaru-llm + free Google search (default), or bring your own key for ChatGPT/Gemini/DeepSeek/Grok/paid Claude
  • Import freelance job listings from aruaru-jobs as a learn-while-you-build prompt
  • A keyboard typing corner, beginner-friendly programming basics, and a JavaScript classroom
  • Learn Japanese, English, or a world language while you code
  • Study BGM: stream commercially-safe background music from archive.org (Public Domain / CC0 / CC-BY / CC-BY-SA only), with play/pause, volume, skip, rewind/fast-forward, and track/performer display
  • Optional maid-cafe voice touches (a greeting, spoken replies) via the browser-standard Web Speech API

これは何？

Maid Cafe Programming Schoolは、 aruaru-llmのAI先生 (aruaru-searchによる 無制限・APIキー不要の検索を裏付けとする)へ、エディタ上で選択中のコードや ファイルパスを自動的に添えて質問できる、無料・オープンソースのVS Code拡張機能です。 open-englishのブラウザ版チャットだけでは、エディタ上の コンテキスト(選択範囲・ファイルパス)を渡せず、「一緒に開発しながら学ぶ」という 体験がチャットの往復コピペに限定されてしまう、という限界を超えるために作られました。

主な機能:

  • コマンドパレット、またはステータスバーのアイコンから、選択中のコード+ファイルパスを添えてAI先生に質問
  • 開発を進めながら、関連する基礎知識も同時に学べる(ONにした場合)
  • AI先生を切替可能: aruaru-llm+無料Google検索(既定)、またはご自身のAPIキーでChatGPT/Gemini/DeepSeek/Grok/有料版Claude
  • aruaru-jobsのフリーランス案件を、「一緒に学習しながら開発したい」という依頼文として取り込み
  • キーボードタイピングコーナー・幼稚園児にも分かるプログラミング基礎教室・JavaScript教室
  • 日本語・英語・世界の言語を、開発しながら同時に学習
  • 学習中BGM: archive.orgの商用利用可能な音源(パブリックドメイン・CC0・CC-BY・CC-BY-SAのみ)をストリーミング再生。再生/一時停止・音量調整・スキップ・巻き戻し/早送り・曲名/歌手名表示に対応
  • メイドカフェ風のしゃべり演出(出迎え挨拶・回答の読み上げ、ブラウザ標準のWeb Speech API使用、任意)

Learn while you build, with aruaru-search + aruaru-llm

Alongside the completely free aruaru-search + aruaru-llm AI teacher, you can choose free-trial ChatGPT, DeepSeek, or Grok, or — the most capable but paid option — Claude Code Desktop. Combined with open-english, you can learn Japanese, English, or a world language together with an AI, while also using freelance job listings and internet news as material for language learning, programming practice, and even learning to build mobile apps and websites — all while enjoying building something real together.

How to use it

  1. Make sure aruaru-llm is running locally (default http://127.0.0.1:4600)
  2. Install the extension from the VS Code Marketplace — search "Maid Cafe Programming School" inside VS Code's Extensions view, or install from the command line:
    code --install-extension aon-co-jp.maid-cafe-programming-school
  3. Select some code (optional), then run "Maid Cafe School: Ask the AI Teacher" from the command palette, or click the 🎓 status-bar icon
  4. Open "Maid Cafe School: Open Menu" to toggle study mode, choose your AI teacher, turn Study BGM on, and more

Honest disclosure: this extension implements no AI inference, search, or music generation of its own — it is a thin client that talks to your own locally running aruaru-llm (and, for Study BGM, aruaru-search's archive.org search, proxied through aruaru-llm). If aruaru-llm isn't running, you'll see an honest connection error rather than a fake answer.

日本語

使い方

  1. aruaru-llmをローカルで起動しておく(既定 http://127.0.0.1:4600)
  2. VS CodeのExtensionsビュー内検索で「Maid Cafe Programming School」を検索してインストール、またはコマンドラインから:
    code --install-extension aon-co-jp.maid-cafe-programming-school
  3. お好みでコードを選択してから、コマンドパレットで「Maid Cafe School: Ask the AI Teacher」を実行、またはステータスバーの🎓アイコンをクリック
  4. 「Maid Cafe School: Open Menu」から、学習モードの切替・AI先生の選択・学習中BGMのON/OFF等を行えます

正直な開示: この拡張機能自体には、AI推論・検索・音楽生成のいずれも実装されていません ——お使いのローカルaruaru-llm(学習中BGMは、そこ経由でプロキシされる aruaru-searchのarchive.org検索)へ問い合わせるだけの薄いクライアントです。 aruaru-llmが起動していない場合は、それらしい回答をでっち上げるのではなく、 正直に接続エラーを表示します。
