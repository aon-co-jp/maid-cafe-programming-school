# Maid Cafe Programming School 方針 / Policy

## 日本語
- **薄いクライアントを保つ**: AI推論・検索は aruaru-llm / aruaru-search に任せ、拡張機能は実装しない。呼び出しは Connect(POST)のみで、REST は使わない。
- **正直な開示**: できないこと・未確認のことは README・CLAUDE.md に書く。スクールとしての不足(カリキュラム・自動採点・進捗・人の支援・アカウント)を隠さない。
- **自動採点を優先**: 「学習の手応え」はAI任せにせず、ローカルでテストを実行した合否で出す。
- **公開**: GitHub Release の `.vsix` は公開済み。VS Code Marketplace はユーザー自身の発行者トークンが要るため、こちらでは行わない。
- **ライセンス**: 学習中BGMはパブリックドメイン・CC0・CC-BY・CC-BY-SA のみ。CC-BY(-SA) はクレジット表示を常に行う。

## English
- **Stay a thin client**: AI inference and search are left to aruaru-llm / aruaru-search; the extension implements none. Calls use Connect (POST) only; no REST.
- **Honest disclosure**: write what is not possible or not verified in README and CLAUDE.md. Do not hide the gaps as a school (curriculum, auto-grading, progress, human support, accounts).
- **Auto-grading first**: the sense of learning must not rest on the AI alone; it comes from pass/fail of tests run locally.
- **Publishing**: the `.vsix` on GitHub Releases is published. The VS Code Marketplace needs the user's own publisher token, so it is not done here.
- **Licenses**: study BGM is limited to Public Domain, CC0, CC-BY and CC-BY-SA; CC-BY(-SA) credits are always shown.
